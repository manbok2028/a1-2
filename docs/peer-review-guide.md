# 동료 평가 안내서

## 프로젝트를 한 문장으로 설명하면

여행 날짜를 입력하면 LLM이 구조화된 여행 추천 JSON을 만들고, Kakao Local API가 맛집을 검색한 뒤, 최종 Markdown 여행 리포트를 저장하는 Python CLI 프로그램입니다.

## 빠르게 확인할 항목

1. `README.md`의 API 키 설정 방법과 키 비노출 주의 사항을 확인합니다.
2. `python -m travel_planner --date "2026-10-10" --demo --refresh`로 키 없이 결과 파일 구조를 확인합니다.
3. `results/2026-10-10_raw.json`에 추천 JSON·도시별 맛집·`errors` 배열이 있는지 확인합니다.
4. `results/2026-10-10_travel_plan.md`에 추천 지역·이유·날씨·행사·맛집·1일 일정·오류 요약이 있는지 확인합니다.
5. `--demo` 없이 실행했을 때 키가 없으면 설정 안내가 나오는지 확인합니다.
6. 코드에서 LLM JSON 파싱 재시도가 최대 1회인지, Kakao 오류가 리포트 생성을 멈추지 않는지 확인합니다.

## 보너스 과제 확인

| 보너스 | 확인 방법 |
|---|---|
| 복수 지역 추천 | `Recommendation.recommended_cities`와 도시별 반복 맛집 검색 |
| 결과 캐싱 | 같은 날짜 재실행 시 `[cache]` 로그와 외부 API 호출 생략, `--refresh`로 강제 새로고침 |

## 피드백 관점

- CLI 로그와 결과 경로 안내가 이해하기 쉬운지
- API 키 보안·오류 처리 정책이 현실적인지
- JSON 데이터를 다음 API 입력으로 연결하는 흐름이 명확한지
- 맛집이 0건이거나 API 인증 오류일 때도 리포트가 유용한지

자세한 정책은 [API 설계·보안·오류 처리 문서](api-design-and-security.md)를 참고하세요.
