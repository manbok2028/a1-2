PYTHON · OPENAI COMPATIBLE API · KAKAO LOCAL API

국내 여행지 추천
CLI 프로그램

여행 날짜와 원하는 지역을 입력하면 AI 추천, 날씨 가이드, 행사·계절 참고, 지역별 맛집·장소 검색 결과를 JSON과 Markdown 리포트로 정리하는 Python 프로젝트입니다.

학습·평가용 프로젝트 안내
이 페이지는 Python CLI 결과물을 설명하는 정적 소개 페이지입니다. --demo 모드는 외부 API를 호출하지 않으며, 표시되는 데모 맛집은 실제 영업 정보가 아닌 예시입니다. 실제 여행 전에는 공식 날씨와 장소 정보를 다시 확인하세요.
1. AI 추천날짜·선호 지역을 바탕으로 추천 도시와 날씨·행사 정보를 구조화된 JSON으로 받습니다.
2. 장소 검색Kakao Local API로 지역별 맛집·장소를 검색하고 오류가 나도 리포트 생성을 이어갑니다.
3. 리포트 저장결과를 Markdown과 JSON으로 저장하고 같은 날짜는 캐시로 재사용합니다.

안전한 데모 실행

python -m pip install --no-deps .
python -m travel_planner --date "2026-10-11" --demo --refresh

--demo는 API 키 없이도 날씨 가이드와 지역별 장소·맛집이 포함된 리포트 구조를 확인하는 모드입니다.
