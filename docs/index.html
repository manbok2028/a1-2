이 Pages는 무엇인가요?

실행 프로그램 자체는 Python CLI입니다. 이 웹 페이지는 저장소 안의 코드 구조, 동작 흐름, 실행 방법, 데모 결과를 평가자와 사용자가 한눈에 확인할 수 있도록 만든 공개 프로젝트 소개 페이지입니다.

한 번의 실행으로 정리되는 여행 준비

단순히 지역 이름만 추천하는 프로그램이 아닙니다. 추천 근거·여행 시기 참고·행사/계절 정보·장소 검색 결과·오류 내역을 하나의 결과물로 남겨, 나중에 확인하거나 다시 실행하기 쉽게 설계했습니다.

01

AI 지역 추천

날짜와 선택 지역을 바탕으로 LLM이 추천 도시, 날씨/계절 가이드, 행사 참고, 추천 이유를 JSON으로 생성합니다.

02

실제 장소 검색

추천 도시마다 Kakao Local API를 호출해 상호명, 분류, 주소, 장소 URL, 좌표를 수집합니다.

03

리포트·캐시 저장

읽기 쉬운 Markdown과 기계 처리용 JSON을 함께 저장하고, 같은 날짜의 결과는 캐시로 재사용합니다.

실제 코드의 3단계 처리 흐름

1. 추천 JSONGemini API에 날짜·선호 도시를 전달하고, 정해진 스키마의 JSON 응답을 받습니다.
→
2. Kakao 장소 검색추천·입력 도시별로 맛집과 장소를 검색합니다. 검색 실패도 오류 기록으로 남깁니다.
→
3. 최종 리포트LLM Markdown 리포트와 원본 JSON을 results/에 저장합니다.

API 키 없이 확인하는 데모 실행

--demo는 외부 API를 호출하지 않습니다. 그래서 비용이나 키 노출 없이도 전체 파이프라인, 결과 파일, 캐시 동작을 안전하게 검증할 수 있습니다.

PS> python -m pip install --no-deps .
PS> python -m travel_planner --date "2026-10-11" --demo --refresh

데모 리포트에 포함되는 항목

추천 지역: 강릉·속초여행 시기 가이드행사·계절 참고1일 일정
  • 강릉: 바다식당, 커피정원, 초당순두부길
  • 속초: 중앙시장 먹거리, 항구회관, 설악카페
  • 각 장소에 분류와 예시 주소를 함께 표시

데모 장소명과 주소는 학습용 예시임을 명시합니다. 실제 API 실행 시에는 Kakao Local 검색 결과로 대체됩니다.

안정성과 재사용을 고려한 설계

문제 상황프로젝트의 처리 방식
LLM이 JSON 형식을 어김필수 필드를 검증하고, JSON 전용 보정 요청을 최대 1회만 재시도합니다.
Kakao 인증·네트워크·쿼터 오류오류를 errors에 기록합니다. 장소 목록은 비어 있어도 전체 리포트 생성은 계속합니다.
같은 날짜를 여러 번 실행JSON과 Markdown이 모두 있으면 캐시를 재사용합니다. 새 요청이 필요할 때만 --refresh를 사용합니다.
사용자 지역 입력이 자연어임--cities에서 별칭을 보정하고 복수 도시를 추출하여, 지역이 아닌 단어는 검색어에서 분리합니다.
API 키를 저장소에 올릴 위험.env와 환경 변수로만 키를 읽고, .gitignore로 제외합니다.
실제 실행 전 확인

날씨·행사·영업 정보는 변할 수 있습니다. 실제 여행 전에는 기상청과 장소의 공식 안내를 다시 확인해야 하며, API 키는 코드·README·스크린샷·Git 커밋에 절대 포함하면 안 됩니다.
